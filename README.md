# Assembly Forge

3D-песочница для сборки машин: модульные детали, физика и текстовое программирование на GDScript.
Прототип на Godot 4 / GDScript, физический движок — Jolt Physics.

## Текущий статус

**Шаг 1 — каркас редактора.** Физики, деталей и хотбара пока нет: в сцене лежат демонстрационные точки.

- орбитальная камера (ПКМ, СКМ, колесо, Home);
- объёмная сетка 0.5 м с осями X/Y/Z;
- выделение точек кликом и рамкой (Shift + ЛКМ);
- перемещение точек с привязкой X/Y/Z к сетке;
- удаление, отмена и повтор действий.

## Управление

| Действие | Клавиша / мышь |
| --- | --- |
| Вращение камеры | ПКМ + движение мыши |
| Панорама | СКМ + движение мыши |
| Зум | Колесо мыши |
| Сброс камеры | Home |
| Выбрать / переместить точку | ЛКМ по точке |
| Рамка выделения | Shift + ЛКМ |
| Снять выделение | Клик ПКМ или ЛКМ по пустоте |
| Удалить выделенное | Delete / Backspace |
| Отмена / повтор | Ctrl+Z / Ctrl+Shift+Z |

## Запуск

1. Открыть папку проекта в Godot 4.7+.
2. Нажать F5.

## Структура

```
scenes/main.tscn              главная сцена и UI
scripts/main.gd               запуск, демо-точки, связь UI
scripts/editor/               камера, сетка, точки, выделение, история
scripts/ui/selection_box.gd   рамка выделения
shaders/editor_grid.gdshader  шейдер сетки
```
