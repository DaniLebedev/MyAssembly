# Assembly Forge

3D-песочница для сборки конструкций: сетка, точки, балки, панели и кубы.
Стек: Godot 4 / GDScript, физика — Jolt Physics.

## Текущий этап

**Шаг 1–2: каркасный редактор и моделирование в стиле Blender.**

Реализовано:

- свободная камера (вращение, панорама, зум, сброс);
- сетка 0.5 м по осям X/Y/Z;
- выделение точек, балок, панелей, кубов, шарниров и моторов (ЛКМ, Shift+ЛКМ, рамка);
- перемещение G с привязкой к сетке;
- осевой замок X / Y / Z во время G и E;
- выдавливание E: точка → балка, линия → плоскость, треугольник → призма,
  квадрат/панель → куб;
- заполнение F: 2 точки → балка, 3 точки → треугольник, 4 точки → панель,
  4 балки по контуру → панель, 8 точек → куб;
- панели и кубы F/E получают `MeshInstance3D` и `CollisionShape3D`
  (`ConcavePolygonShape3D`), вершины жёстко связаны с точками;
- сварка M: точки в центре, Ctrl+M — в первую, Ctrl+Shift+M — в последнюю;
  две балки соединяются концами или выравниваются в одну линию;
- меню пресетов Tab / кнопка «СОЗДАТЬ»: куб 2×2×2, плоскость 4×4, балка 3 м,
  шарнир и мотор появляются перед камерой;
- круговое меню на ПКМ (удержание): куб, плоскость, балка, шарнир, мотор;
- шарнир и мотор: две точки крепления, ось, коллизия; у мотора — скорость
  и крутящий момент;
- балка притягивается к ближайшему креплению шарнира/мотора при спавне,
  а M на паре «балка + шарнир/мотор» жёстко прикрепляет её к креплению;
- удаление X / Delete с каскадным удалением связанных деталей;
- отмена и повтор Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y;
- контекстные подсказки и панель состояния.

## Управление

| Действие | Клавиши / мышь |
| --- | --- |
| Выделить | ЛКМ |
| Добавить / снять с выделения | Shift + ЛКМ |
| Рамка выделения | ЛКМ в пустоту + протягивание (Shift добавляет) |
| Сбросить выделение | ЛКМ в пустоту / короткий ПКМ / Esc |
| Меню пресетов деталей | Tab или кнопка «СОЗДАТЬ» |
| Круговое меню деталей | удерживать ПКМ, выбрать сектор, отпустить |
| Двигать выделенное | G, затем ЛКМ — подтвердить, ПКМ / Esc — отмена |
| Выдавить | E, затем ЛКМ — подтвердить, ПКМ / Esc — отмена |
| Заполнить / обновить грань | F |
| Сварить точки / балки | M |
| Прикрепить балку к шарниру / мотору | выделить балку и деталь, затем M |
| Сварить все точки в первую | Ctrl + M |
| Сварить все точки в последнюю | Ctrl + Shift + M |
| Осевой замок при G / E | X / Y / Z (повторное нажатие снимает) |
| Удалить | X / Delete / Backspace |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z (или Ctrl+Y) |
| Вращение камеры | СКМ или Alt + ЛКМ |
| Панорама | Shift + СКМ |
| Зум | Колесо мыши |
| Сброс камеры | Home |

## Моделирование

- **E на точке** создаёт балку до новой точки.
- **E на линии (2 точки или балка)** создаёт плоскость: 4 точки, панель и
  4 балки по периметру.
- **E на треугольнике (3 точки или 3 балки по контуру)** создаёт призму:
  верхнюю и нижнюю грани, 3 боковые панели и 9 рёбер.
- **E на квадрате/панели (4 точки)** создаёт куб: 6 граней и 12 рёбер.
- **F на 2 точках** создаёт балку.
- **F на 3 точках** создаёт треугольную грань.
- **F на 4 точках** создаёт четырёхугольную грань.
- **F на 4 балках по контуру** заполняет контур панелью.
- **M на точках** сваривает их; связанные балки и грани переходят на общую
  точку, а вырожденные элементы удаляются.
- **M на двух балках** соединяет ближайшие концы или выравнивает балки по
  одной линии.
- **M на балке и шарнире/моторе** переносит ближайший конец балки в точку
  крепления и жёстко связывает детали.
- **Tab** открывает меню пресетов. **Куб** — 8 точек, куб и 12 рёбер;
  **плоскость** — 4 точки, панель и 4 балки; **балка** — 3 м; **шарнир** и
  **мотор** — по 2 точки крепления и физическая коллизия.
- **ПКМ с удержанием** открывает круговое меню вокруг курсора. Отпускание ПКМ
  в секторе сразу создаёт выбранную деталь перед камерой.
- У мотора есть параметры `speed` (рад/с) и `torque` (Н·м); физическое
  вращение будет подключено на следующем этапе.

## Запуск

1. Откройте папку проекта в Godot 4.7+.
2. Нажмите F5.

## Структура

```

scripts/editor/               контроллер, камера, сетка, точки, балки, панели, кубы,
                              шарниры и моторы
scripts/ui/selection_box.gd   рамка выделения
scripts/ui/spawn_menu.gd      меню пресетов Tab
scripts/ui/radial_menu.gd     круговое меню ПКМ
shaders/editor_grid.gdshader  сетка редактора
```
